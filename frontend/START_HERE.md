## 🔐 Security

```
User Input
   ↓
Form Validation
   ↓
API Call (with JWT token)
   ↓
Interceptor (handles 401, refreshes token)
   ↓
Backend Processing
   ↓
Response (stored in Zustand + localStorage)
```
